# Institute of Informatics

Website of the Institute of Informatics (FERI, University of Maribor): a Next.js site with
a built-in Payload CMS for editors.

**Live:** https://ii-preview.bclabum.si · **CMS:** https://ii-preview.bclabum.si/admin

## For editors

Sign in at `/admin` with the link we email you (no password); an administrator adds you
first. Changes are live as soon as you publish. See [CMS_GUIDE.md](CMS_GUIDE.md).

## For developers

```bash
corepack enable
pnpm install
cp .env.example .env.local          # local database + secrets
pnpm payload migrate                # create the schema
pnpm dev                            # site on :3000, CMS on :3000/admin
```

Details in [DEVELOPMENT.md](DEVELOPMENT.md); hosting and CI in [DEPLOYMENT.md](DEPLOYMENT.md).

## How it works

```
Browser ─► Next.js app (one container)
            ├─ /, /en/…            public site, rendered from CMS content and cached
            ├─ /admin              Payload admin panel
            └─ /api                Payload REST API and uploaded media
                    │
                    └─► Postgres
```

- Pages render on the first request and stay cached. Publishing in the CMS purges the cache,
  so the next visitor sees the change.
- Editors preview drafts with **Live Preview** before publishing.
- Slovenian lives at `/…`, English at `/en/…`; every text field in the CMS has both languages,
  and English falls back to Slovenian where it is empty.

## Project structure

```
src/
├── app/
│   ├── (frontend)/[locale]/   ← public pages (one tree for SL and EN)
│   ├── (frontend)/next/       ← preview (draft mode) routes
│   └── (payload)/             ← CMS admin + REST API (generated by Payload)
├── collections/, globals/     ← CMS content types
├── components/                ← shared UI (PageShell, cards, …); ui/ = shadcn components
├── i18n/                      ← UI translations and URL helpers
├── lib/                       ← data access (payload.ts), media, preview URLs
├── migrations/                ← database schema migrations
└── proxy.ts                   ← maps un-prefixed URLs to the Slovenian locale
public/                        ← logos, static files
```

## Tech stack

- **Next.js 16** (App Router, React Server Components)
- **Payload CMS 3** with Postgres
- **shadcn/ui** + **Tailwind CSS 4**
- **Biome** for linting and formatting
- **Docker** on bclabum, deployed by GitHub Actions
